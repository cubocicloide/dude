# FE012 — index.tsx hygiene

The `index.tsx` of a component, hook, or page should contain **that one thing** and nothing else. Everything else has a canonical home in the same scope, and FE012 warns until it is moved there:

| Found in index.tsx | Move it to |
|--------------------|-----------|
| `interface` / `type` declarations | `types.tsx` |
| A second component | Its own directory under `$components/` |
| A `use*` hook (in a component/page) | Its own directory under `$hooks/` |
| A component (in a hook) | A `$components/` scope — hooks must not render |
| Top-level helper functions / arrow consts | `functions.tsx` |

```tsx
// ❌ pages/users/index.tsx
interface Row { … }                      // → types.tsx
const toLabel = (u: User) => …           // → functions.tsx
function UserBadge() { … }               // → $components/UserBadge/
export default function UsersPage() { … }

// ✅ pages/users/index.tsx
import type { Row } from './types'
import { toLabel } from './functions'
import { UserBadge } from './$components'
export default function UsersPage() { … }
```

Only **top-level** declarations count — helpers defined inside the component body are fine. The check is heuristic and warning-only, but keeping `index.tsx` thin is what makes the matrioska structure navigable.
