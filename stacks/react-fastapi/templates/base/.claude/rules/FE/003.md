# FE003 — $components barrel file

Every `$components/` folder that contains at least one component must have an `index.tsx` barrel that re-exports **all** PascalCase child directories:

```tsx
export { default as TodoTable } from './TodoTable'
export { default as UserCard } from './UserCard'
```

- One `export { default as X }` line per component, no other code.
- Keep entries in alphabetical order.
- A missing barrel is an error; a missing export is an error.
- **Adding a new component = add its export to the barrel in the same PR.**
- Applies at every nesting level (matrioska): a `$components/` inside `UserCard/` needs its own barrel.
