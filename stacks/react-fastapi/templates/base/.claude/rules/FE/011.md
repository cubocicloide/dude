# FE011 — $misc is a temporary escape hatch

Any scope (component, hook, page, utils domain) may contain a `$misc/` folder. Its content is **exempt from all structure checks** — when you genuinely don't know where something belongs yet, park it there instead of violating the structure.

But every `$misc/` raises a **warning**, always. Treat it as a to-do: empty it as soon as you know better.

| What's in $misc | Where it belongs |
|-----------------|------------------|
| A component | Its own directory under the scope's `$components/` |
| A hook / store | Its own directory under a `$hooks/` |
| Shared types | The scope's `types.tsx` |
| Pure functions | The scope's `functions.tsx` |
| Constants | The scope's `constants.tsx` |
| Static files | The scope's `$assets/` |
| Cross-cutting helpers | A domain in `frontend/src/utils/` |

Never let `$misc/` accumulate: the warning stays until the folder is gone.
