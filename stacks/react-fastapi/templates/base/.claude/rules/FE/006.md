# FE006 — Hook directory naming and contents

Direct children of any `$hooks/` folder must be hook directories matching `^use[A-Z][a-zA-Z0-9]*$`.

| Valid | Invalid |
|-------|---------|
| `useAttachments/` | `useattachments/` |
| `useTodoList/` | `todo-list/` |

A hook directory may contain **only**:

| Item | Required? |
|------|-----------|
| `index.tsx` | **Mandatory** (error if missing) |
| `styles.module.css`, `types.tsx`, `constants.tsx`, `functions.tsx` | Optional |
| `$assets/` | Optional |
| `$misc/` | Escape hatch — always warned (FE011) |

No `$components/` inside a hook — a hook should not own components. Privileged folders are not allowed directly inside `$hooks/` (they belong inside a hook directory). `$hooks/` folders exist at the top level (`src/$hooks/`) and locally inside components and pages.
