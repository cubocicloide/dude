# FE008 — Static assets live in $assets/ folders

Static assets never float around the tree: each one lives in the `$assets/` folder of the scope that uses it (component, hook, page, or utils domain).

**Covered extensions:** `.svg` `.png` `.jpg` `.jpeg` `.gif` `.webp` `.avif` `.ico` `.pdf` `.json` `.txt` `.csv` `.mp4` `.webm` `.mp3` `.wav` `.ogg` `.woff` `.woff2` `.ttf` `.otf` `.eot`

Rules:

1. **An asset outside a `$assets/` folder is an error.**
2. **`$assets/` may only contain assets** — files with no code in them (images, fonts, media, documents, data). A `.ts`/`.tsx`/`.css` file inside `$assets/` is an error.
3. **Naming**: asset filenames are kebab-case with a lowercase extension — `user-guide.pdf`, `logo-dark.svg`, `empty-state.png` (warning otherwise). Subdirectories inside `$assets/` are kebab-case too.

```tsx
// ✅ correct — asset owned by the component that uses it
import logo from './$assets/logo.svg'

// ❌ wrong — asset dropped next to the code
import logo from './Logo.svg'
```

If an asset is shared by several scopes, attach it to their closest common ancestor scope (e.g. the page's `$assets/` when two page-local components use it).
