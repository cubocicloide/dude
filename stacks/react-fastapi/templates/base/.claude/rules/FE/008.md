# FE008 — Static assets location

All static assets must live exclusively in `frontend/src/assets/`. Placing asset files elsewhere under `frontend/src/` is an error.

**Covered extensions:** `.svg` `.png` `.jpg` `.jpeg` `.gif` `.webp` `.avif` `.ico` `.pdf` `.mp4` `.mp3` `.ogg` `.woff` `.woff2` `.ttf` `.eot`

```
frontend/src/
├── assets/       ✅  logo.svg, hero.png, fonts/…
├── components/   ❌  never place assets here
└── pages/        ❌  never place assets here
```

**Import from anywhere using the `@/` alias:**

```tsx
// ✅ correct
import logo from '@/assets/logo.svg'
import heroUrl from '@/assets/hero.png'

// ❌ wrong – asset inside a component folder
import logo from './Logo.svg'
```

When adding a new asset, always drop it into `frontend/src/assets/` (create the folder if it does not yet exist).
