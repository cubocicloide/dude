# FE002 — Allowed contents of a component directory

A component directory may contain **only**:

| Item | Required? |
|------|-----------|
| `index.tsx` | **Mandatory** (error if missing) |
| `styles.module.css` | Optional |
| `types.tsx` | Optional |
| `constants.tsx` | Optional |
| `functions.tsx` | Optional |
| `$components/` | Optional — nested sub-components (same rules apply recursively) |
| `$hooks/` | Optional — hooks used only by this component |
| `$assets/` | Optional — static files used only by this component |
| `$misc/` | Escape hatch — always warned (FE011) |

Any other file or subdirectory raises a warning.

```
UserCard/
  index.tsx
  styles.module.css
  constants.tsx
  $components/
    Avatar/
      index.tsx
  $assets/
    placeholder.png

UserCard/
  index.tsx
  utils.ts            ← FE002 warning → move to functions.tsx
  components/         ← FE002 warning → use $components/
```
