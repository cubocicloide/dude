# FE007 — $hooks barrel file

Every `$hooks/` folder that contains at least one hook must have an `index.tsx` barrel that re-exports **all** `use*` directories:

```tsx
export { default as useCounterStore } from './useCounterStore'
export { default as usePageTitle } from './usePageTitle'
```

- The alias name must exactly match the directory name.
- A missing barrel is an error; a missing export is an error.
- **Adding a new hook = update the barrel in the same PR.**
- No named re-exports, no `export *`, no JSX.
- Applies to every `$hooks/` folder, including page-local and component-local ones.
