# BE006 — Router filename convention

Router filenames must follow: `{resource}[_{sub}][__{param}].py`

- Segments are **lowercase alphanumeric**, separated by `_` (sub-resource) or `__` (path parameter).

| Filename | Maps to path prefix |
|----------|---------------------|
| `todos.py` | `/todos` |
| `todos__id.py` | `/todos/{id}` |
| `users_me.py` | `/users/me` |
| `keycloak_token.py` | `/keycloak/token` |
