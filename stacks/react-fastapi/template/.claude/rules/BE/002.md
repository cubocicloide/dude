# BE002 — Model class naming

Each `backend/app/models/foo.py` must define a class named after the file (snake_case → PascalCase).

| File | Required class |
|------|---------------|
| `models/user.py` | `class User` |
| `models/todo_item.py` | `class TodoItem` |

See also BE010 (one class per file).
