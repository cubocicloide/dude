# BE009 — Centralised environment variables

All env vars must be read **exclusively** in `backend/app/core/config.py` via a `BaseSettings` subclass. Using `os.getenv` or `os.environ` anywhere else is an error.

```python
# core/config.py — correct
class Settings(BaseSettings):
    DATABASE_URL: str
    SECRET_KEY: str

settings = Settings()
```

```python
# routers/todos.py — wrong
import os
db_url = os.getenv("DATABASE_URL")  # BE009 error
```

**Additional rule**: fields in `Settings` must be declared in **alphabetical order**.

To add an env var: add it to `Settings` in `core/config.py`, then reference it as `settings.MY_VAR`.
