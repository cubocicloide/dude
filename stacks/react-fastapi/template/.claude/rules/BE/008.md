# BE008 — 1-to-1 test coverage

Every source file in `models/`, `queries/`, `routers/`, `utils/` must have a corresponding test file, and vice-versa.

| Source | Expected test |
|--------|---------------|
| `models/todo.py` | `tests/models/test_todo.py` |
| `routers/todos.py` | `tests/routers/test_todos.py` |

- **Warning**: source exists, test is missing → add the test.
- **Error**: test exists, source is missing → orphaned test; remove it or create the source.

Adding a source file → create the test file in the same PR.
