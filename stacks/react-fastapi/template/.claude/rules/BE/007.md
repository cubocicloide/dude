# BE007 — Router file contents & path consistency

A router file may contain **only** `@router.METHOD`-decorated async functions. No helpers, no classes, no utilities — put those in `utils/`.

Each route's path must match the path derived from the filename (BE006 rules):

```python
# File: routers/todos__id.py  →  expected prefix: /todos/{id}
@router.get("/{id}")      # ✓
@router.get("/todos/{id}")  # ✗ — prefix is set by include_router in main.py
```

Path derivation:
- `__param` → `/{param}` (path parameter)
- `_segment` → `/segment` (literal segment)
- All functions in the file share this base prefix.
