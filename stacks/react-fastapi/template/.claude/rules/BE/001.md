# BE001 — Required `backend/app/` structure

`backend/app/` must contain **all** of the following directories and files.

**Required directories:**
```
core/  fixtures/  management/  models/  queries/  routers/  schemas/  tasks/  tests/  utils/
```

**Required root files:** `main.py`, `__init__.py`

**Required layout inside `tests/`:**
```
tests/
  models/  queries/  routers/  tasks/  utils/
  __init__.py
  conftest.py
```

When adding a new resource, create all required files in the same PR.
