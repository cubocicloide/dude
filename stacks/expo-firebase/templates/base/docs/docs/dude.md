# Working with dude

Run `dude help` for the live command catalog and `dude cheatsheet` for commands,
lint rules, init answers, and the verification loop in one view.

Structural diagnostics use `RNxxx` and `FBxxx` codes. Run
`dude explain <CODE>` to read the matching rule before changing code. Project
specific checks can be added below `.dude/lint/checks/`.
