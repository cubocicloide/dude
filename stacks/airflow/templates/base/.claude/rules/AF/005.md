# AF005 — default_args from lib.defaults (error)

Every DAG imports the shared defaults and passes them as `default_args`:

```python
from lib.defaults import DEFAULT_ARGS

with DAG(dag_id="example_etl", default_args=DEFAULT_ARGS, ...):
```

Extend, don't fork, when a DAG needs something extra:

```python
with DAG(..., default_args={**DEFAULT_ARGS, "retries": 5}):
```

Why: owner, retries and retry backoff are *policy*. When they live in
`airflow/dags/lib/defaults.py` a policy change is one edit; copy-pasted
per-DAG dicts drift silently.

**Fix**: add `from lib.defaults import DEFAULT_ARGS` and pass
`default_args=DEFAULT_ARGS` (or an extended copy) to the DAG.
