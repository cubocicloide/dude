# AF004 — every DAG is tagged (error)

Every DAG must set a non-empty `tags=[…]`.

Why: tags are the only first-class grouping/filter mechanism in the Airflow
UI. Once the project has a few dozen DAGs, an untagged DAG is effectively
lost. Use stable, lowercase tags: the owning team, the domain, and (for the
scaffold's examples) `examples`.

✅

```python
with DAG(dag_id="example_etl", tags=["examples", "etl"], ...):
```

❌

```python
with DAG(dag_id="example_etl", ...):        # no tags
with DAG(dag_id="example_etl", tags=[], …): # empty tags
```

**Fix**: add at least one meaningful tag.
