# AF002 — explicit schedule, no schedule_interval (error)

Every DAG must pass `schedule=` explicitly. `schedule_interval=` was removed
in Airflow 3 — a file that still uses it fails to import.

Why: the schedule is the single most important operational fact about a DAG;
relying on a default forces every reader to remember it.

✅

```python
with DAG(dag_id="example_etl", schedule="@daily", ...):
with DAG(dag_id="manual_only", schedule=None, ...):
```

❌

```python
with DAG(dag_id="example_etl", ...):                      # implicit schedule
with DAG(dag_id="legacy", schedule_interval="@daily", …): # removed in Airflow 3
```

**Fix**: add `schedule="<cron or preset>"`, a Timetable instance, or
`schedule=None` for manual-only DAGs.
