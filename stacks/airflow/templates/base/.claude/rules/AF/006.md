# AF006 — no Variable/Connection access at parse time (error)

`Variable.get()`, `BaseHook.get_connection()` and
`Connection.get_connection_from_secrets()` must not run at DAG-parse time —
that is module scope **or** the body of a `with DAG(...):` block. Only code
inside task functions runs at task runtime.

Why: the dag-processor re-imports every DAG file continuously (every ~30s).
A parse-time `Variable.get` hits the metadata DB / secrets backend on every
cycle, for every file, forever.

✅

```python
@task
def load():
    target = Variable.get("target_bucket")   # runs only when the task runs

# or resolve it lazily via templating:
BashOperator(task_id="x", bash_command="echo {{ var.value.target_bucket }}")
```

❌

```python
TARGET = Variable.get("target_bucket")       # module scope: every parse

with DAG(...) as dag:
    conn = BaseHook.get_connection("pg")     # DAG body: still every parse
```

**Fix**: move the lookup inside the task callable, or use a Jinja template
(`{{ var.value.x }}`, `{{ conn.pg.host }}`).
