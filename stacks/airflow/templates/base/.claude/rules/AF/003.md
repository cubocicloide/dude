# AF003 — explicit catchup (error)

Every DAG must set `catchup=` explicitly.

Why: whether unpausing a DAG back-fills every missed interval since
`start_date` is the most surprising Airflow behaviour there is. Each DAG must
state its choice where the reader can see it.

✅

```python
with DAG(dag_id="example_etl", schedule="@daily", catchup=False, ...):
```

**Fix**: add `catchup=False` (the right answer for almost every DAG), or
`catchup=True` when back-filling is genuinely intended.
