# BE004 — No raw SQL (error)

`Model.objects.raw(...)`, `cursor.execute(...)`, `RawSQL(...)` and `connection.cursor()` are forbidden in application code. Raw SQL bypasses the ORM's parameter escaping (injection risk), model-layer validation, and database portability.

```python
# ✅
User.objects.filter(is_active=True).order_by("-date_joined")
```

```python
# ❌
User.objects.raw("SELECT * FROM users WHERE active = 1")
cursor.execute(f"DELETE FROM users WHERE id = {user_id}")
```

**Fix**: express the query through the ORM (`filter`, `annotate`, `aggregate`, `Subquery`, …). If a query genuinely cannot be expressed with the ORM, isolate it and get it reviewed — do not scatter raw SQL through app code.
