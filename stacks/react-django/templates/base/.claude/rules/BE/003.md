# BE003 — Explicit permission_classes (error)

Every DRF view class (`APIView`, `GenericAPIView`, any `*ViewSet`, `generics.*`) must declare `permission_classes` in its body. Relying on the project-wide default hides the endpoint's real exposure from reviewers; the intent must be visible at the view.

The project default (`DEFAULT_PERMISSION_CLASSES = IsAuthenticated`) is a safety net, not a substitute for the declaration.

```python
# ✅
class UserViewSet(ReadOnlyModelViewSet):
    permission_classes = [IsAuthenticated]
```

```python
# ❌ — who can call this? You can't tell from the code.
class UserViewSet(ReadOnlyModelViewSet):
    queryset = User.objects.all()
```

**Fix**: add an explicit `permission_classes = [...]` to the view class.
