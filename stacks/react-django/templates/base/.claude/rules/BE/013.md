# BE013 — Typed OpenAPI schema (warning)

Every DRF view class must either declare `serializer_class` or carry a drf-spectacular `@extend_schema` / `@extend_schema_view` annotation. Without one, the endpoint appears untyped in `/api/schema/` — and the generated TypeScript client (`dude api sync`) degrades to `unknown` for that route.

```python
# ✅ either of these
class UserViewSet(ReadOnlyModelViewSet):
    serializer_class = UserSerializer

@extend_schema(responses=HealthSerializer, tags=["health"])
class HealthView(APIView):
    ...
```

```python
# ❌ schema (and TS client) has no idea what this returns
class HealthView(APIView):
    def get(self, request):
        return Response({"status": "ok"})
```

**Fix**: set `serializer_class`, or annotate with `@extend_schema(request=..., responses=...)`. Then run `dude api sync`.
