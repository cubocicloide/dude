# BE002 — Explicit serializer fields (error)

`ModelSerializer.Meta` must list its fields explicitly. `fields = "__all__"` and `exclude = (...)` are forbidden: they silently expose every new model column — adding `password_reset_token` to the model would leak it through the API without any diff to the serializer.

```python
# ✅
class UserSerializer(serializers.ModelSerializer):
    class Meta:
        model = User
        fields = ("id", "username", "email")
```

```python
# ❌
class UserSerializer(serializers.ModelSerializer):
    class Meta:
        model = User
        fields = "__all__"      # or: exclude = ("password",)
```

**Fix**: enumerate exactly the fields the endpoint should expose.
