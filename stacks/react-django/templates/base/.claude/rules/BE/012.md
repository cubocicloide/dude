# BE012 — No `print()` — use logging (warning)

`print()` in app/config code bypasses log levels, formatting and routing. Containers forward stdout, but only the logging module gives you severity filtering, structured context and per-logger control (see `LOGGING` in `base.py`).

```python
# ✅
import logging

logger = logging.getLogger(__name__)
logger.info("user created: %s", user.pk)
```

```python
# ❌
print(f"user created: {user.pk}")
```

Tests and migrations are exempt. **Fix**: swap for a module-level `logger`.
