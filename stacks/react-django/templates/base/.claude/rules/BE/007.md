# BE007 — Settings hygiene (error)

In every settings module except `local.py`:

1. `SECRET_KEY` must not be a hard-coded string literal — it comes from the environment (`env("DJANGO_SECRET_KEY")`). A committed secret is a leaked secret.
2. `DEBUG = True` must not appear — debug mode exposes stack traces, settings and SQL to the world. Only `local.py` (development) may enable it.

```python
# ✅ production.py
SECRET_KEY = env("DJANGO_SECRET_KEY")   # required, no default
DEBUG = False

# ✅ local.py — development only
SECRET_KEY = env("DJANGO_SECRET_KEY", default="dev-insecure-key")
DEBUG = True
```

```python
# ❌ base.py / production.py
SECRET_KEY = "django-insecure-abc123"
DEBUG = True
```

**Fix**: read the value from the environment; keep permissive defaults confined to `local.py`.
