# BE011 — Explicit `related_name` on relations (warning)

`ForeignKey`, `OneToOneField` and `ManyToManyField` should pass an explicit `related_name`. The implicit `<model>_set` reverse accessor is brittle (renaming the model silently renames the accessor) and unreadable at call sites.

```python
# ✅
owner = models.ForeignKey(User, on_delete=models.CASCADE, related_name="uploads")
# user.uploads.all()
```

```python
# ❌
owner = models.ForeignKey(User, on_delete=models.CASCADE)
# user.fileupload_set.all()  ← what is this?
```

**Fix**: name the reverse relation after what the collection *is* from the other side (use `related_name="+"` when the reverse accessor is intentionally unwanted).
