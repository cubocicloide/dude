# BE008 — URL structure (error)

Two invariants keep routing predictable:

1. Every `apps/<app>/urls.py` defines `app_name = "<app>"` — URL namespacing makes `reverse("users:users-list")` unambiguous as apps multiply.
2. `config/urls.py` mounts each app's URLconf under the `api/` prefix via `include("apps.<app>.urls")` — one place to see the whole API surface, and the ALB/edge router can path-route `/api/*` as a unit.

```python
# ✅ apps/users/urls.py
app_name = "users"
router = DefaultRouter()
router.register("users", UserViewSet, basename="users")
urlpatterns = router.urls

# ✅ config/urls.py
path("api/", include("apps.users.urls")),
```

**Fix**: add the missing `app_name` and/or the `include(...)` line in `config/urls.py`.
