# BE014 — Every app ships tests (error)

Every Django app under `backend/apps/` must contain a `tests/` package (`__init__.py` included) with at least one `test_*.py` file. An app with zero tests has zero executable documentation of its behaviour — regressions land silently.

```
apps/users/
└── tests/
    ├── __init__.py
    ├── test_models.py   # ✅ at least one test_*.py
    └── test_views.py
```

Convention: mirror the module you exercise (`test_models.py`, `test_views.py`, `test_services.py`). Use `pytest.mark.django_db` for DB access and DRF's `APIClient` for endpoint tests.

**Fix**: create `tests/__init__.py` and a first real test — the health/users apps in this scaffold show the pattern.
