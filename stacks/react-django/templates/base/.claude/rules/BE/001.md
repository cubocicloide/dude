# BE001 — App registration parity (error)

Every Django app under `backend/apps/<name>/` (any directory containing an `apps.py`) must be registered as `"apps.<name>"` in the `LOCAL_APPS` list of `config/settings/base.py`, and every `LOCAL_APPS` entry must have a matching directory on disk.

An unregistered app silently ships dead code (models never migrated, urls never mounted); a stale entry crashes Django at boot.

```python
# ✅ config/settings/base.py
LOCAL_APPS = [
    "apps.core",
    "apps.users",
]
```

```python
# ❌ backend/apps/reports/ exists but LOCAL_APPS lacks "apps.reports"
```

**Fix**: add the app to `LOCAL_APPS` (or delete the leftover directory/entry).
