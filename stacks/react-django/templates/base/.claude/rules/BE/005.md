# BE005 — No ORM writes in views (error)

`views.py` must not perform write operations on the ORM (`objects.create/update_or_create/get_or_create/bulk_*`, queryset `.update(...)` / `.delete()`). Views orchestrate: they validate input via serializers and delegate writes to the app's `services.py` (or the serializer's `create`/`update`).

Keeping writes in one layer makes business rules testable without HTTP, reusable from Celery tasks and management commands, and keeps views trivially thin.

```python
# ✅ views.py
class UserViewSet(ReadOnlyModelViewSet):
    queryset = User.objects.all()          # read-only queryset attr is fine

# ✅ services.py
def create_user(*, username: str, email: str) -> User:
    return User.objects.create(username=username, email=email)
```

```python
# ❌ views.py
def post(self, request):
    User.objects.create(**request.data)
```

**Fix**: move the write into `apps/<app>/services.py` (or the serializer) and call it from the view.
