# BE009 — Model `__str__` and `Meta.ordering` (warning)

Every model should define:

- `__str__` — otherwise the admin, shell and logs show `User object (42)`.
- `Meta.ordering` — DRF's `PageNumberPagination` over an unordered queryset is non-deterministic: rows can repeat or vanish across pages.

```python
# ✅
class User(AbstractUser):
    class Meta:
        ordering = ("id",)

    def __str__(self) -> str:
        return self.username
```

**Fix**: add both members. Choose an ordering backed by an index (usually the pk or a timestamp).
