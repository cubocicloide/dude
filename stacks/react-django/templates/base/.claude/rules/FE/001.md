# FE001 — Component directory naming

Every direct child directory of any `$components/` folder (top-level, page-local, or nested inside another component) must be PascalCase: `^[A-Z][a-zA-Z0-9]+$`.

| Valid | Invalid |
|-------|---------|
| `UserCard/` | `userCard/` |
| `TodoTable/` | `todo-table/` |

Privileged `$`-folders (`$assets`, `$hooks`, `$misc`, …) are **not** allowed directly inside a `$components/` folder — they belong **inside** a component directory:

```
$components/
  $assets/          ← FE001 error (no owner)
  UserCard/
    $assets/        ✅ owned by UserCard
```
