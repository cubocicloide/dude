# FE010 — src root layout and $types

The root of `frontend/src/` is fixed:

```
src/
  App.tsx              ← routes + providers
  main.tsx             ← entry point
  styles.module.css    ← global styles (use :global(...) selectors)
  $types/              ← ALL *.d.ts ambient declarations (e.g. vite-env.d.ts)
  $components/         ← shared components
  $hooks/              ← shared hooks (incl. zustand stores)
  openapi/             ← generated API client (dude api sync)
  pages/               ← route tree
  utils/               ← pure helpers, by domain
```

- Legacy entries are **errors** with a migration hint: `components/` → `$components/`, `hooks/` → `$hooks/`, `assets/` → per-scope `$assets/`, `index.css` → `styles.module.css`, `vite-env.d.ts` → `$types/vite-env.d.ts`.
- Any other file/directory at the src root is an error.
- `$types/` may **only** contain `*.d.ts` files, and every `*.d.ts` under `src/` must live there (both errors).
