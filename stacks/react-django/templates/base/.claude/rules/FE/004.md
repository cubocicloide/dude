# FE004 — Route ↔ directory 1-to-1

Every `@/pages/<name>` import in `App.tsx` must have a matching `frontend/src/pages/<name>/` directory, and vice-versa.

- **Error**: `App.tsx` imports a page that does not exist on disk.
- **Warning**: a `pages/<name>/` directory exists but is not imported in `App.tsx`.

Adding a new page → create the directory **and** add the import + `<Route>` in `App.tsx` in the same PR.
