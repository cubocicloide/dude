# FE004 — Route ↔ page node 1-to-1

A **page node** is any directory under `frontend/src/pages/` (including the root) whose `index.tsx` renders a route. Every `@/pages/...` import in `App.tsx` must have a matching page node, and vice-versa.

| Import in App.tsx | Page node on disk |
|-------------------|-------------------|
| `@/pages` | `pages/index.tsx` |
| `@/pages/users` | `pages/users/index.tsx` |
| `@/pages/users/[id]` | `pages/users/[id]/index.tsx` |

- **Error**: `App.tsx` imports a page whose `index.tsx` does not exist on disk.
- **Warning**: a page node exists but is not imported in `App.tsx`.
- `$`-prefixed folders (`$components/`, `$hooks/`, …) are structural — they are never route segments.

Adding a new page → create the directory **and** add the import + `<Route>` in `App.tsx` in the same PR. A `[param]` directory maps to a `:param` route path (`pages/users/[id]` → `<Route path="/users/:id">`).
