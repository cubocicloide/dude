# DT002 — DocTypes must declare permissions (error)

Every DocType JSON must have a non-empty `permissions` array in which at
least one entry names a `role`.

Frappe's permission model is **deny-by-default**: a DocType with no
permission rules is invisible and unusable for every user except
`Administrator`. That "works" in development (you are Administrator) and then
fails for the first real user — the classic Frappe rookie trap.

```json
// ✅ ticket_escalation_rule.json
"permissions": [
  {
    "role": "System Manager",
    "read": 1, "write": 1, "create": 1, "delete": 1,
    "email": 1, "export": 1, "print": 1, "report": 1, "share": 1
  }
]
```

**Fix**: add a permissions entry per role that needs access (start with
`System Manager`, add end-user roles deliberately). Prefer editing the JSON in
the app (or Desk UI with developer mode on) over site-local Custom
Permissions, so the rules ship with the code.
