# DT003 — DocType naming and module registration (error)

Three naming invariants tie a DocType to its place on disk:

1. `scrub(name)` (lowercase, spaces → underscores) must equal the doctype
   directory name: `"Ticket Escalation Rule"` → `ticket_escalation_rule/`;
2. the JSON's `module` must be listed in the app's `modules.txt`;
3. `scrub(module)` must equal the module directory the doctype lives under:
   module `"Ticketing"` → `ticketing/doctype/<name>/`.

Frappe locates a DocType's code purely from these conventions (`module` +
scrubbed name → path). Break any of them and `bench migrate` either fails or
— worse — imports the schema while never finding your controller.

```text
✅ modules.txt:  Ticketing
   JSON:         "name": "Ticket Escalation Rule", "module": "Ticketing"
   Path:         ticketing/ticketing/doctype/ticket_escalation_rule/
```

**Fix**: rename the directory to the scrubbed DocType name, add the module to
`modules.txt`, or move the bundle under the right module directory. When you
add a new module, remember every module in `modules.txt` needs a matching
`<scrubbed_module>/` package directory in the app.
