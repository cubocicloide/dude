# DT001 — DocType bundle completeness (error)

Every DocType directory
`apps/<app>/<app>/<module>/doctype/<doctype_name>/` must contain the full
bundle: `<doctype_name>.json` (the schema), `<doctype_name>.py` (the
controller) and `__init__.py`. The form script (`.js`) and tests are optional
(tests are nudged separately by PY003).

Frappe loads DocTypes by convention from exactly these paths. A missing
controller means `frappe.get_doc(...)` falls back to a generic `Document`
with none of your validation; a missing `__init__.py` breaks imports; a
missing JSON means the DocType simply doesn't exist on migrate.

```text
✅ apps/ticketing/ticketing/ticketing/doctype/ticket_escalation_rule/
     __init__.py
     ticket_escalation_rule.json
     ticket_escalation_rule.py
     ticket_escalation_rule.js          # optional
     test_ticket_escalation_rule.py     # optional (see PY003)
```

**Fix**: add the missing file. For a new DocType, copy the
`ticket_escalation_rule` bundle as a starting point, or create it in the Desk
UI with developer mode on (frappe writes the bundle into the app for you).
