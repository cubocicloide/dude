# APP002 — scheduler_events handlers must resolve (error)

Every dotted path declared in the `scheduler_events` dict of `hooks.py`
(e.g. `"ticketing.tasks.escalate_overdue_tickets"`) must resolve to an
existing module file inside the app with a matching `def <function>(`.

The scheduler resolves these paths at **runtime**, per tick: a typo doesn't
fail on install or on boot — the job just never runs, and the only trace is a
Scheduled Job Log entry most people never read. This check makes the failure
visible at lint time.

```python
# ✅ hooks.py
scheduler_events = {
    "hourly": ["ticketing.tasks.escalate_overdue_tickets"],  # tasks.py defines it
}

# ❌ hooks.py
scheduler_events = {
    "hourly": ["ticketing.tasks.escalate_overdue_ticket"],   # typo — silently dead
}
```

**Fix**: correct the dotted path, or create the function in the module the
path points at. Test a job by hand with
`dude bench --site <site> execute ticketing.tasks.escalate_overdue_tickets`.
