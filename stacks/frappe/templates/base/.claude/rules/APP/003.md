# APP003 — doc_events handlers must resolve (error)

Every handler declared in the `doc_events` dict of `hooks.py`
(e.g. `"ticketing.events.hd_ticket.after_insert"`) must resolve to an existing
module file inside the app with a matching `def <function>(`.

`doc_events` is how an app extends DocTypes owned by *other* apps (e.g.
Helpdesk's `HD Ticket`) without forking them. Like scheduler events, the
paths are resolved at runtime on every document save — a broken path either
throws on every save of that DocType or (depending on the frappe version)
silently skips your logic.

```python
# ✅ hooks.py
doc_events = {
    "HD Ticket": {
        "after_insert": "ticketing.events.hd_ticket.after_insert",
    },
}
# with apps/ticketing/ticketing/events/hd_ticket.py defining
#   def after_insert(doc, method=None): ...
```

**Fix**: correct the dotted path or create the handler function. Handlers
take `(doc, method)` — see `apps/ticketing/ticketing/events/hd_ticket.py`.
