# APP001 — Frappe app layout integrity (error)

Every directory under `apps/` that ships a `pyproject.toml` must be a complete
Frappe app: a Python package `apps/<app>/<app>/` containing `hooks.py`,
`modules.txt`, `patches.txt` and `__init__.py`. A directory with Python files
but no `pyproject.toml` gets a warning — `docker/init.sh` only links
directories that look like real apps, so it would silently be ignored.

These four files are the app's contract with the framework: `bench install`
reads `hooks.py` and `modules.txt`, `bench migrate` reads `patches.txt`.
A missing file doesn't fail loudly — the app just half-works.

```text
✅ apps/ticketing/
     pyproject.toml
     ticketing/
       __init__.py
       hooks.py
       modules.txt
       patches.txt

❌ apps/my_app/            # has my_app/tasks.py but no pyproject.toml
```

**Fix**: scaffold apps with `dude app new --name <app>` (wraps `bench
new-app`), or add the missing file(s) by copying them from `apps/ticketing/`.
