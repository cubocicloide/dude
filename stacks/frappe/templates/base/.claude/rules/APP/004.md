# APP004 — Fixtures declared ↔ shipped (error)

The `fixtures` list in `hooks.py` and the JSON files in
`apps/<app>/<app>/fixtures/` must match in both directions:

- every declared fixture DocType (`{"dt": "Workflow"}` or plain `"Workflow"`)
  needs a `fixtures/<scrubbed_name>.json` file (`Workflow State` →
  `workflow_state.json`);
- every `fixtures/*.json` file must be declared in `hooks.py`.

`bench migrate` imports fixtures **from the declaration list**: a declared-
but-missing file breaks installs on a fresh site, while an undeclared file is
dead weight that everyone assumes is being imported — the worst kind of
config drift.

```python
# ✅ hooks.py — masters first, then the docs that link to them
fixtures = [
    {"dt": "Workflow State", "filters": [["name", "in", ["Draft", "Approved", "Rejected"]]]},
    {"dt": "Workflow Action Master", "filters": [["name", "in", ["Approve", "Reject"]]]},
    {"dt": "Workflow", "filters": [["name", "in", ["Ticket Escalation Rule Approval"]]]},
]
```

**Fix**: after changing fixture records in the Desk UI, export them with
`dude bench --site <site> export-fixtures` (writes the JSON files), and keep
the `fixtures` list in `hooks.py` in sync. Remove stale files/declarations.
