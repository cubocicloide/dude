# FE007 — Hooks barrel export

`src/hooks/index.tsx` must re-export every `use*` directory:

```tsx
export { default as usePageTitle } from './usePageTitle'
export { default as useTauriEvent } from './useTauriEvent'
```

Consumers import hooks from `@/hooks`, never from a deep path. When you add a
hook directory, add its barrel export in the same change.
