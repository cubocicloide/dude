# FE009 — IPC only through src/ipc/ wrappers

Pages, components and hooks must never import `@tauri-apps/api/core`
(`invoke`) directly, and must never touch the `window.__TAURI__` global. Every
Rust command gets exactly one typed wrapper module in `src/ipc/`:

```ts
// src/ipc/greet.ts
import { invoke } from '@tauri-apps/api/core'

export async function greet(name: string): Promise<string> {
  return invoke<string>('greet', { name })
}
```

Consumers call `greet(name)` from `@/ipc`. This keeps command names and
payload shapes in one greppable place, typed once — when a Rust signature
changes, only the wrapper changes.

Note: argument keys are camelCase in TS and snake_case in Rust; Tauri converts
automatically.
