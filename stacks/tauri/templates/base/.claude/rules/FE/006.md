# FE006 — Hook directory contents

Each hook lives in its own `use<Name>/` directory under `src/hooks/`,
containing only:

- `index.tsx` — the hook implementation
- `types.tsx` — hook-local types (optional)

The directory name must start with `use` followed by an uppercase letter
(`useTauriEvent/`, `usePageTitle/`).
