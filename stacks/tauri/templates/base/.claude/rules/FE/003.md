# FE003 — Components barrel export

`src/components/index.tsx` must re-export every PascalCase component directory:

```tsx
export { default as Layout } from './Layout'
export { default as UserCard } from './UserCard'
```

Pages import shared components from `@/components`, never from a deep path.
When you add a component directory, add its barrel export in the same change.
