# FE010 — Events only through useTauriEvent

Do not import `@tauri-apps/api/event` (`listen`, `once`, `emit`) in pages or
components. `listen()` resolves **asynchronously** to an unlisten function;
forgetting to await and call it on unmount is the classic Tauri listener leak
(double subscriptions under React StrictMode, callbacks firing on unmounted
components).

Subscribe through the hook, which owns the whole lifecycle:

```tsx
import { useTauriEvent } from '@/hooks'

useTauriEvent<number>('counter-changed', (value) => setCounter(value))
```

Event *names* are exported as constants from the matching `src/ipc/` module
(e.g. `COUNTER_CHANGED_EVENT`), next to the commands that emit them.
