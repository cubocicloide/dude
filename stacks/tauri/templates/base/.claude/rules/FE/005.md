# FE005 — Page directory contents

A page directory may only contain:

- `index.tsx` — the page component
- `styles.module.css` — scoped styles (optional)
- `types.tsx` — page-local types (optional)

Reusable pieces extracted from a page move to `src/components/` (shared) or
`src/hooks/` (logic), not to extra files inside the page directory.
