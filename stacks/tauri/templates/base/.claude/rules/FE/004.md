# FE004 — Pages ↔ App.tsx routing parity

Imports of `@/pages/<Name>` in `src/App.tsx` must match the directories in
`src/pages/` one-to-one:

- **error** — App.tsx imports a page whose directory does not exist;
- **warning** — a page directory exists but is never routed in App.tsx.

When you add a page, wire its `<Route>` in App.tsx in the same change; when
you remove a route, delete the page directory too.
