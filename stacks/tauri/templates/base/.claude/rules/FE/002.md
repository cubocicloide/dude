# FE002 — Component directory contents

A component directory may only contain:

- `index.tsx` — the component itself
- `styles.module.css` — scoped styles (optional)
- `types.tsx` — component-local types (optional)
- `components/` — nested sub-components (optional)

Anything else (helpers, extra components, assets) belongs in `src/utils/`,
its own component directory, or `src/assets/`.
