# FE011 — src/ipc/ layout

The IPC layer stays flat: one `.ts` module per Rust command domain, mirroring
`src-tauri/src/commands/` one-to-one, plus an `index.ts` barrel that
re-exports every module:

```
src/ipc/
├── index.ts     # export * from './greet'; export * from './counter'
├── greet.ts     # ↔ src-tauri/src/commands/greet.rs
└── counter.ts   # ↔ src-tauri/src/commands/counter.rs
```

No subdirectories, no non-TypeScript files. Consumers import from `@/ipc`,
never from a deep path. When you add a Rust command module, add the matching
ipc module and its barrel export in the same change.
