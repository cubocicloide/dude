# BE001 — Required src-tauri layout

The Rust backend keeps this fixed skeleton:

```
src-tauri/
├── Cargo.toml
├── build.rs
├── tauri.conf.json
├── capabilities/          # permission grants per window
└── src/
    ├── main.rs            # thin binary entry (see BE002)
    ├── lib.rs             # Builder: plugins, state, invoke_handler
    ├── error.rs           # shared AppError (see BE006)
    ├── state.rs           # managed AppState
    └── commands/
        ├── mod.rs         # declares every command module (see BE004)
        └── <domain>.rs    # one module per command domain
```

Do not remove or rename these files; add new domains as
`src/commands/<domain>.rs`.
