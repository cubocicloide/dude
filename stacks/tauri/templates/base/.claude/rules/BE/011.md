# BE011 — Command modules ship unit tests

Every `src-tauri/src/commands/<domain>.rs` ends with a `#[cfg(test)] mod
tests` block exercising its logic. Run them with `dude test`.

Keep commands thin so this is easy: put the domain logic in plain functions
(taking `&Connection`, plain values, …) and let the `#[tauri::command]`
binding only extract state and delegate — the tests then cover the logic
without a running app:

```rust
fn apply_increment(current: i64, amount: i64) -> Result<i64, AppError> { … }

#[tauri::command]
pub fn increment_counter(…) -> Result<i64, AppError> {
    // lock state, call apply_increment, emit event
}

#[cfg(test)]
mod tests {
    #[test]
    fn increments_by_amount() { … }
}
```
