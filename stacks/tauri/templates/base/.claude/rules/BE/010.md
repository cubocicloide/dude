# BE010 — Capabilities: explicit and minimal

Every file in `src-tauri/capabilities/` must be valid JSON declaring:

- `identifier` — a unique capability name;
- `windows` — the explicit window labels it applies to (e.g. `["main"]`);
- `permissions` — the explicit permissions those windows need.

Grant the least privilege that works: prefer `core:window:allow-set-title`
over a whole plugin default when one permission suffices, and avoid wildcard
entries. When you add a plugin or use a new window API, add exactly the
permission the runtime error asks for — nothing broader.
