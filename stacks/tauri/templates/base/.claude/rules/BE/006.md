# BE006 — Fallible commands return Result<_, AppError>

Every command that can fail returns the shared error type from
`src-tauri/src/error.rs`:

```rust
#[tauri::command]
pub fn greet(name: &str) -> Result<String, AppError> { … }
```

Never `Result<T, String>` or ad-hoc error types: `AppError` implements
`Serialize`, so the frontend always receives a consistent rejection message,
and `#[from]` conversions let bodies propagate with `?`.

To support a new failure domain, add a variant to `AppError` (with
`#[error(…)]` and, where possible, `#[from]`) rather than mapping errors by
hand at each call site.
