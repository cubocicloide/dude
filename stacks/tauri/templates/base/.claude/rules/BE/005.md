# BE005 — invoke_handler registration parity

Every `#[tauri::command]` must be registered in the `generate_handler![…]`
list in `lib.rs`, and every registered name must exist as a command:

```rust
.invoke_handler(tauri::generate_handler![
    commands::greet::greet,
    commands::counter::get_counter,
    commands::counter::increment_counter,
])
```

A command missing from the list **compiles fine but fails at runtime** with
"command not found" the first time the frontend invokes it. When you add,
rename or delete a command, update `generate_handler!` (and the `src/ipc/`
wrapper) in the same change.
