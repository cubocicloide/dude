# BE008 — Log with the log crate, not print macros

`println!`, `eprintln!`, `print!`, `eprint!` and `dbg!` write to a console the
packaged app doesn't have. Use the `log` crate macros, which
`tauri-plugin-log` routes to the log file, stdout (dev) and the webview
devtools console:

```rust
log::info!("counter incremented to {value}");
log::warn!("settings file missing, using defaults");
```

Print macros remain fine inside `#[cfg(test)]` blocks.
