# BE003 — Commands live under src/commands/

Every `#[tauri::command]` function is defined in a domain module under
`src-tauri/src/commands/` — never in `lib.rs`, `main.rs`, `state.rs` or
anywhere else.

One module per domain (`greet.rs`, `counter.rs`, `notes.rs`), mirrored
one-to-one by a typed wrapper module in the frontend's `src/ipc/` (rule FE011).
