# BE004 — commands/ module hygiene

- Command module filenames are snake_case (`user_settings.rs`, not
  `userSettings.rs`).
- Every `commands/<domain>.rs` is declared in `commands/mod.rs` as
  `pub mod <domain>;`
- Every `mod` declaration in `commands/mod.rs` has a matching file (no
  orphan declarations).

When you add or remove a command module, update `mod.rs` in the same change.
