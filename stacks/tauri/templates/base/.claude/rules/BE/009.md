# BE009 — tauri.conf.json hygiene

Two settings are checked because their broken states fail silently:

- **identifier** — must be a real reverse-domain identifier
  (`com.acme.myapp`), never the `com.tauri.dev` placeholder. It names the
  bundle, the app-data directory and the updater identity; changing it later
  orphans user data.
- **app.security.csp** — must not be `null`. The CSP is the webview's main
  script-injection defence; Tauri augments whatever you set with its own
  nonces/hashes at runtime. Extend the existing policy rather than disabling
  it (e.g. add `img-src` sources), and keep it as strict as the app allows.
