# BE002 — main.rs stays thin

`main.rs` contains exactly one thing: the delegation to the library crate.

```rust
fn main() {
    app_lib::run();
}
```

No `tauri::Builder`, no `#[tauri::command]`, no logic. All setup lives in
`lib.rs` (`run()`), so the same code path serves the desktop binary and any
future mobile entry point (`#[cfg_attr(mobile, tauri::mobile_entry_point)]`),
and the app can be exercised from tests.
