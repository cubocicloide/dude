# BE007 — No unwrap/expect in command modules

A panic inside a command crashes the whole desktop app — there is no request
isolation like in a web server. In `src-tauri/src/commands/`, never call
`.unwrap()` or `.expect()` outside `#[cfg(test)]` blocks.

Propagate errors instead:

```rust
let dir = app.path().app_data_dir()?;          // via #[from] on AppError
let value = maybe.ok_or_else(|| AppError::InvalidInput("missing value".into()))?;
```

For poisoned mutexes, recover rather than panic:

```rust
let guard = state.counter.lock().unwrap_or_else(|e| e.into_inner());
```
