# MCP003 — Sub-server contract

A feature becomes mountable only if it follows the sub-server contract across
two files.

**`_server.py`** must define a module-level server whose name equals the feature
folder:

```python
from fastmcp import FastMCP

server = FastMCP(name="calculator")   # in features/calculator/_server.py
```

The `name` must be a string literal equal to the folder name — the root server
mounts sub-servers by it, and a mismatch makes the feature unfindable.

**`__init__.py`** must do two things:

1. **Re-export `server`** so the root can mount it:
   ```python
   from ._server import server
   __all__ = ["server"]
   ```
2. **Trigger component registration** — the `@server.tool`/`resource`/`prompt`
   decorators only run when their modules are imported. Either call
   `import_submodules(__name__, __path__)` (from `utils.discovery`) or import the
   component packages directly (`from . import tools, resources, prompts`).

Without registration the components are defined but never attached to `server`.
