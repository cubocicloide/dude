# MCP014 — Centralised configuration

Mirrors react-fastapi BE009. Environment variables are read in **one place only**:
`app/config.py`, via a Pydantic `BaseSettings` subclass. Everywhere else under
`app/`, `os.getenv` and `os.environ` are forbidden.

```python
# app/config.py
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    api_key: str
    timeout: int = 30

settings = Settings()
```

Elsewhere, import the settings instead of reaching for the environment:

```python
from app.config import settings
client = Client(api_key=settings.api_key)
```

- Using `os.getenv` / `os.environ` outside `config.py` is an **error**.
- A missing `config.py` is a **warning** — create it to centralise env access.

To fix: move the env read into the `Settings` class and import `settings` where
the value is needed.
