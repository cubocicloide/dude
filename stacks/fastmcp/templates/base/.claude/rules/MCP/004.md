# MCP004 — Component placement & purity

Each kind of MCP component lives only in its matching package:

| Decorator | Allowed location |
|-----------|------------------|
| `@server.tool` | a feature's `tools/` package |
| `@server.resource` | a feature's `resources/` package |
| `@server.prompt` | a feature's `prompts/` package |

Anywhere else — `server.py`, `config.py`, `schemas/`, the global `utils/`, a
feature's `utils/`, or a `core/` — must contain **no** component decorators.
A `@server.resource` inside `tools/` is also a violation: the package and the
decorator must agree.

This keeps the tree navigable: a component's kind is implied by its path, and the
non-component layers stay free of MCP wiring.

To fix: move the decorated function into the correct `tools/`, `resources/`, or
`prompts/` package of its feature.
