# MCP009 — Context convention

When a component needs the MCP `Context` (for progress, logging, sampling, …),
it must follow a fixed convention:

1. The parameter is **named `ctx`**. A parameter annotated `Context` under any
   other name is a violation.
2. The `ctx` parameter is **annotated `Context`**.
3. Any component that takes `ctx` — or references `ctx.` in its body — must be
   `async def`, because the Context API is awaited.

```python
@server.tool
async def summarize(text: str, ctx: Context) -> str:
    """Summarize text, reporting progress."""
    await ctx.info("summarizing")
    return service.summarize(text)
```

To fix: rename the parameter to `ctx`, annotate it `Context`, and make the
function `async def` when it uses the context.
