# MCP013 — No duplicate tool/prompt names or resource URIs

All features mount into a single **flat namespace**. Two features must not export:

- the same **tool** name,
- the same **prompt** name, or
- the same **resource URI**.

At mount time a collision silently shadows one of the components — the loser
simply disappears with no error. This rule catches that across the whole server,
listing every feature involved in a clash.

```
# features/math/tools/add.py        → tool "add"
# features/vectors/tools/add.py     → tool "add"   ← collision
```

To fix: rename one of the colliding components (and its module, per MCP005), or
give the resources distinct URIs. Names only need to be unique across the whole
server, not just within a feature.
