# MCP012 — Naming conventions

All folder and module names under `app/`, and every component function name, must
be `snake_case`.

| Subject | Example (ok) | Example (bad) |
|---------|--------------|---------------|
| feature folder | `features/note_store/` | `features/NoteStore/` |
| component module | `tools/create_note.py` | `tools/createNote.py` |
| component function | `def create_note(...)` | `def createNote(...)` |

`snake_case` keeps Python imports, the file tree, and the mounted component names
consistent across the server.

To fix: rename the offending folder, `.py` module, or function to `snake_case`.
When renaming a component module, remember the function must still match the
module stem (see MCP005).
