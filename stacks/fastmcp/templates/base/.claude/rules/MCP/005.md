# MCP005 — One component per module, named after the module

Each component module defines **exactly one** decorated component, and its
function is named after the module stem:

```python
# features/calculator/tools/add.py
@server.tool
def add(a: int, b: int) -> int:
    ...
```

The same applies to `resources/<name>.py` and `prompts/<name>.py`.

This 1-module-1-component rule is what makes the tree scale: a component is found
by its path, and diffs and tests (MCP017) stay local to one file.

Violations:

- **No decorated function** in the module → add the `@server.*` component, or
  remove the empty module.
- **More than one** decorated component → split each into its own module.
- **Function name ≠ module stem** → rename the function to match the file
  (`add.py` → `def add(...)`).
