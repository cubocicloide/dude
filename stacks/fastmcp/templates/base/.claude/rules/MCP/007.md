# MCP007 — Full type annotations

Every parameter (except the injected `ctx`) and the return type of a decorated
component must be annotated. FastMCP derives the component's JSON schema — the
contract the client and model see — directly from the type hints.

```python
@server.tool
def add(a: int, b: int) -> int:   # every param + return annotated
    """Return the sum of two integers."""
    return service.add(a, b)
```

- `ctx` (and `self`) are exempt — they are injected, not part of the schema.
- A missing parameter annotation produces an incomplete schema.
- A missing return annotation (`-> …`) is also flagged.

To fix: annotate the offending parameter and add a return type. Use `-> None`
when the component returns nothing.
