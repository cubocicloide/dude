# MCP002 — Feature package shape

Each feature is a self-contained sub-server under `features/<name>/`. Every
feature directory (non-underscore name) must contain:

| Item | Role |
|------|------|
| `__init__.py` | Re-exports `server` and triggers component registration (see MCP003). |
| `_server.py` | Declares the feature's `FastMCP` sub-server (see MCP003). |
| at least one of `tools/` / `resources/` / `prompts/` | The MCP components this feature exposes. |
| `utils/` | The feature's logic layer (`service.py` + helpers). |

Every component package that is present, plus `utils/`, must carry its own
`__init__.py` so it is an importable package.

To fix a violation: add the missing `__init__.py` or `_server.py`, add at least
one component package, or add the `utils/` package. A feature with no
`tools/`, `resources/`, or `prompts/` exposes nothing and is flagged.
