# MCP017 — 1-to-1 test coverage

Mirrors react-fastapi BE008. Every operational module has a matching test under
the mirrored `tests/` path, and every test has a matching source module.

| Source | Expected test |
|--------|---------------|
| `features/<f>/tools/<x>.py` | `tests/features/<f>/tools/test_<x>.py` |
| `features/<f>/resources/<x>.py` | `tests/features/<f>/resources/test_<x>.py` |
| `features/<f>/prompts/<x>.py` | `tests/features/<f>/prompts/test_<x>.py` |
| `features/<f>/utils/<x>.py` | `tests/features/<f>/utils/test_<x>.py` |
| `utils/<x>.py` (global) | `tests/utils/test_<x>.py` |

`__init__.py` files are excluded.

- **Warning**: source exists but the test is missing → add the test file.
- **Error**: a `test_<x>.py` exists with no matching source → orphaned test;
  remove it or create the source it claims to cover.

Adding a source module → create its test in the same change.
