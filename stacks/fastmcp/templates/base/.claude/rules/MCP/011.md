# MCP011 — Schema module conventions

Mirrors react-fastapi BE003. Every class in `app/schemas/<m>.py` must:

1. **Extend `BaseModel` or `SQLModel`** — only Pydantic/SQLModel schemas belong
   in `schemas/`.
2. **Be named with the PascalCase prefix** derived from the filename.

| File | Valid class names |
|------|------------------|
| `schemas/calculator.py` | `Calculator`, `CalculatorInput`, `CalculatorResult` |
| `schemas/note.py` | `Note`, `NoteCreate`, `NoteRead` |

Pydantic models live **only** in `schemas/`. Helper enums and mixins belong in
`utils/`, not here.

To fix: give the class a `BaseModel`/`SQLModel` base, and rename it to start with
the filename's PascalCase prefix — or move a non-schema helper out into `utils/`.
