# MCP006 — Docstring required

Every decorated tool, resource, and prompt function must have a non-empty
docstring. FastMCP uses the docstring as the component's **description** — it is
exactly the text the model reads when deciding whether and how to call the
component.

```python
@server.tool
def add(a: int, b: int) -> int:
    """Return the sum of two integers."""
    return service.add(a, b)
```

A missing or empty docstring leaves the component undescribed and harder for a
model to use correctly.

To fix: add a one-line docstring (or longer) describing what the component does,
phrased for the model that will call it.
