# MCP001 — Required project structure

`fastmcp/app/` is the Python MCP service. Its top-level shape is fixed so every
feature, schema, and test has a known home.

`fastmcp/app/` must contain these files:

| File | Role |
|------|------|
| `__main__.py` | Entry point — runs the composed server (`python -m app`). |
| `server.py` | The root `FastMCP` that mounts each feature's sub-server. |
| `config.py` | The one place env vars are read (a `BaseSettings` subclass). |

…and these directories: `features/`, `schemas/`, `utils/`, `tests/`.

`tests/` must mirror the app — it must contain `tests/features/` and
`tests/utils/`. This keeps the 1-to-1 test layout (see MCP017) discoverable.

To fix a violation, create the missing file or directory. A missing
`fastmcp/app/` directory entirely is reported as a single error — the service
package has not been scaffolded.
